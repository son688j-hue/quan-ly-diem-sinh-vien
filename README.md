# Quản lý điểm sinh viên — Streamlit

## Nội dung
- `app.py`: Web App Streamlit theo đề bài.
- `requirements.txt`: Các thư viện cần cài.
- `TenSTT_pythonproject.ipynb`: Notebook cho phần Python/Pandas trên Colab.
- `HUONG_DAN.md`: Hướng dẫn chạy, đưa lên GitHub và triển khai Streamlit.

## Chạy trên máy tính
Cài Python, mở Terminal/CMD tại thư mục này và chạy:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Lưu ý
Dữ liệu 10 sinh viên hiện tại là dữ liệu mẫu để minh họa. Hãy thay bằng dữ liệu giảng viên yêu cầu nếu có.
